# TG Agent Plugin 0.3.0

Initial public source-only release of the unofficial local agent integration for
Telegram personal accounts in Claude Code and Codex.

## Compatibility

- Tested upstream client: [`gotd/cli v0.11.0`](https://github.com/gotd/cli/releases/tag/v0.11.0)
- Targets: macOS, Linux, and Windows on amd64 and arm64
- Hosts: Claude Code and Codex

TG Agent Plugin is only an installation, workflow, and safety wrapper around
the independent `gotd/cli` client. This release contains no upstream `tg`
binaries and no Telegram credentials, configuration, sessions, or content.

## Known limitations

- Personal accounts only; bots and remote sessions are outside scope.
- Login requires a separate local interactive terminal.
- Upstream versions newer than `v0.11.0` are report-only until a future tested
  plugin release pins them.
- Realtime watch operations require a host-enforced duration or event boundary.
